# Pixel Pioneer — Website starter

This is an independent static website starter for Pixel Pioneer.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — small browser-side enhancement

## Before publishing
1. Replace `CONTACT_EMAIL` in `index.html` with the official enquiry email.
2. Confirm the services, course topics, locations, and claims are accurate.
3. Add the approved Pixel Pioneer logo and official contact details.
4. Connect a real enquiry form provider or CRM. The current contact CTA is an email link, not a database-backed form.
5. Test desktop/mobile layouts and all links.

No domain or DNS settings are changed by these files.
